# My Personal Portfolio Website

Hey there! 👋 I'm **Budida Ajay**, and this is my personal portfolio website that I built from scratch to showcase my journey as a Backend Software Engineer and ML enthusiast.

## 🚀 What I Built

I created this ultra-premium portfolio website using modern web technologies to present my skills, experience, and projects in a professional and engaging way. Here's what I accomplished:

### 🎯 My Approach

I wanted to build something that truly represents who I am as a developer, so I:

- **Designed with purpose**: Created a clean, professional interface that highlights my backend development expertise
- **Focused on performance**: Implemented server-side rendering and optimized loading for the best user experience
- **Made it responsive**: Ensured it looks perfect on every device, from mobile phones to desktop screens
- **Added personality**: Included interactive elements and smooth animations to make it engaging

### 🛠️ Technologies I Used

I chose a modern tech stack that I'm passionate about:

- **Next.js 14** - I love how it handles SSR and makes React development seamless
- **TypeScript** - Type safety is crucial for maintainable code, especially in larger projects
- **TailwindCSS** - My go-to for rapid, consistent styling
- **Framer Motion** - Added smooth animations to bring the site to life
- **Three.js** - Implemented 3D graphics to showcase my technical skills
- **Lucide React** - Clean, consistent icons throughout the site

### 🎨 What I Implemented

**Hero Section**: I created an eye-catching introduction with my name, title, and key contact information. I wanted visitors to immediately understand who I am and what I do.

**About Me**: I wrote a personal narrative about my journey at IIIT Jabalpur and my passion for backend development. I included quick facts and organized my skills into clear categories.

**Experience Section**: I detailed my current role as Project Assistant Intern at Rakumura IT Solutions, highlighting the real-world impact I'm making with enterprise-level projects.

**Contact Integration**: I made it easy for potential employers and collaborators to reach me through multiple channels - email, phone, LinkedIn, and GitHub.

**Theme Support**: I implemented dark/light mode toggle because I believe in giving users choice and accessibility.

### 🔧 Technical Decisions I Made

**Architecture**: I structured the project with a clean component-based architecture, separating concerns and making the codebase maintainable.

**Styling Strategy**: I used TailwindCSS with custom gradients and animations to create a unique visual identity while maintaining consistency.

**Performance Optimization**: I implemented lazy loading, optimized images, and used Next.js built-in optimizations to ensure fast loading times.

**SEO & Accessibility**: I added proper meta tags, structured data, and semantic HTML to make the site discoverable and accessible.

## 🚀 Getting Started

If you want to run my project locally:

```bash
# Clone my repository
git clone https://github.com/Ajay9704/portfolio-website.git
cd portfolio-website

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the result.

## 📁 How I Organized My Project

I structured my project for maximum clarity and maintainability:

```
src/
├── app/                 # Next.js 14 app directory
│   ├── globals.css     # Global styles I wrote
│   ├── layout.tsx      # Root layout with my theme provider
│   └── page.tsx        # Main portfolio page
├── components/          # Reusable components I built
│   ├── sections/       # Page sections (Hero, About, etc.)
│   ├── ui/            # Base UI components
│   └── 3d/            # Three.js components (future enhancement)
├── lib/               # Utility functions I created
└── types/             # TypeScript definitions I wrote
```
